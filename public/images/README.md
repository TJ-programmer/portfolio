Drop Batman-style photos of you in this folder. The portfolio cuts them into a scroll-driven 3D sequence — each photo flies in from the side, lands with mouse parallax + breathing, then exits as the next one takes over.

Naming (name them exactly, numbered 1-6):
- `batman-1.jpg` — Hero / origin shot (appears at the top)
- `batman-2.jpg` — About / the vigilante at work
- `batman-3.jpg` — Skills / in the cave, suit-up
- `batman-4.jpg` — Projects / rooftop at night
- `batman-5.jpg` — Achievements / with allies or the Batmobile
- `batman-6.jpg` — Contact / back to the signal

Any subset works — drop 3 of them and the scroll splits into 3 scenes. If none exist, the procedural 3D figure is used instead.

Tips:
- Portrait / tall crop (2:3 or 9:16) works best; full-body or waist-up with a dark background.
- Generate all 6 in ONE run so the face + suit + lighting stay consistent (see instructions).
- Keep them around 1200-2000px tall.
